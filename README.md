# Hacked 

An application so you can be notified of any data breaches that included your personal information. Available for Windows, macOS, iOS, Android, and more.

![image](https://user-images.githubusercontent.com/3520532/103462956-e4d8a080-4cf6-11eb-8779-ed3cbf600977.png)

## Installation Options

* NEW Choose the latest from the [Releases](https://github.com/LanceMcCarthy/Hacked/releases) page.
  * Windows - Download the `.msixbundle` installer file and run it.
  * macOS   - Download the `.pkg` installer file and run it.
  * Android - Download the `.apk` file and deploy to your phone.
  * iOS     - Download the "sideload" `.ipa` and deploy to your phone.
* Store Install
  * Windows - coming soon
  * macOS   - coming soon
  * Android - coming soon
  * iOS     - coming soon
  * (UWP) Windows 10+, Xbox, Hololens, Windows 10 Mobile [Microsoft Store](https://www.microsoft.com/store/productId/9NBLGGH6850J)
